# Privacy Policy for Radmehr OS

Radmehr OS is an open-source software project. The project itself does not operate a central analytics, advertising, or telemetry service and does not intentionally collect personal data from users.

## Local data

Radmehr OS may store user-provided settings and credentials locally on the user's device, such as display names or API keys. These files are intended to remain on the local computer and are excluded from the public source repository.

## External services

Some optional features connect to third-party services only when the user chooses to use those features. These may include services such as Google Gemini, NASA APIs, and GitHub. Data sent to those services is handled according to the privacy policies and terms of the respective service providers.

Radmehr OS does not independently receive or store the content submitted to those third-party services.

## Source code and transparency

The source code is publicly available at:

https://github.com/radmehrfarhadi/radmehr_os

Users can review the source code to understand how data is handled.

## Changes

This privacy policy may be updated as the project evolves or new features are added.

## Contact

Questions about this privacy policy can be raised through the project's GitHub repository.
